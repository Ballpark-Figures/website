# website

The Ballpark Figures website, served at **[ballparkfigur.es](https://ballparkfigur.es)**
via GitHub Pages.

- `index.html` — the landing page (self-contained; brand colors + Inter font inline).
- `CNAME` — tells GitHub Pages to serve at the custom domain `ballparkfigur.es`.

Static site only (no build step). Edit `index.html` and push to `main`; GitHub Pages
redeploys automatically.
